# NOVA Architecture Freeze

Date: 25-05-2026

This document freezes the core architecture decisions for the NOVA capstone MVP.

## Locked Decisions

- React + Vite frontend
- Express backend
- PostgreSQL database
- FastAPI AI service
- TensorFlow .h5 inference
- Manual input MVP
- No computer vision for MVP
- Existing repo structure retained
- MVP-first development priority

## Goal
Deliver a stable and demo-ready working system within the remaining project timeline.

Major architecture changes are not allowed unless critical.
